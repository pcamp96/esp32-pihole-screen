ESP32 Pi-hole Screen

Turns an ESP32-S3 into a little screen for Pi-hole v6 stats, with a button that pauses blocking for five minutes.

Plug the board in over USB and click Install. You'll need Chrome or Edge on a computer.

Your browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. This page needs to be opened over HTTPS.

If the board doesn't show up in the list, hold BOOT, tap RST, let go of BOOT, and try again.

What you need

  • An ESP32-S3 board with 16MB flash and 8MB PSRAM (sold as N16R8)
  • A 128x64 SSD1306 OLED, an I2C LCD1602, or both
  • A push button (optional, but it's the fun part)
  • Pi-hole v6 and an app password from Settings › Web interface / API (turn on Expert mode to see it)

First boot

  1. On your phone, join the Wi-Fi network PiholeSetup. A setup page opens (or go to 192.168.4.1).
  2. Pick your home Wi-Fi, then fill in your Pi-hole address (like http://192.168.1.2:8080), the app password, and how long a pause lasts.
  3. Save. The board restarts onto your network and starts showing stats.

To change settings later, hold the button while you plug the board in.

Status light

The board's RGB LED shows what it's doing, even without a screen attached.

  • Blue: waiting on the setup page
  • Green: Pi-hole is blocking
  • Amber: blocking is paused
  • Red: can't reach Pi-hole or the password is wrong
