ESP32 Pi-hole Screen

Turns an ESP32-S3 into a little screen for Pi-hole v6 stats, with a button that pauses blocking for five minutes.

Plug the board in over USB and click Install. You'll need Chrome or Edge on a computer.

Fill in your settings to have them written into the firmware, so the board joins your Wi-Fi on its own. Or leave Wi-Fi name blank and enter everything on the board's own setup network after installing.

Your browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. This page needs to be opened over HTTPS.

Loading firmware…

Settings you enter never leave this browser. They're written into a copy of the firmware here and sent to the board over USB. If the board doesn't show up in the list, hold BOOT, tap RST, let go of BOOT, and try again.

What you need

  • An ESP32-S3 board with 16MB flash and 8MB PSRAM (sold as N16R8)
  • A 128x64 SSD1306 OLED, an I2C LCD1602, or both
  • A push button (optional, but it's the fun part)
  • Pi-hole v6 and its password: either the web admin password or an app password from Settings › Web interface / API (turn on Expert mode to see it). Pi-hole keeps only one app password, so making a new one stops anything else that used the old one.

First boot

After installing, the board joins your Wi-Fi and starts showing stats within about 20 seconds. The ESP32 only does 2.4GHz Wi-Fi, so use a network name that has 2.4GHz.

If it can't join, it opens its own Wi-Fi network, PiholeSetup. Join that from a phone and a setup page opens (or go to 192.168.4.1) where you can fix the settings. You can also hold the button while you plug the board in to get there, or just install again from this page with new settings.

Status light

The board's RGB LED shows what it's doing, even without a screen attached.

  • Blue: waiting on the setup page
  • Green: Pi-hole is blocking
  • Amber: blocking is paused
  • Red: can't reach Pi-hole or the password is wrong
